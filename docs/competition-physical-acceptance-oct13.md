October 13, 2026. Implementation and focused simulator verification complete. Physical acceptance is not claimed. Existing dirty work preserved; no commit or push.

## Fixed

- **Top Cubers:** expanded state was local to a reusable hosting graph; recycling could discard it and change a revisited card's height. The Browser now retains an observable disclosure model per competition, observed inside the cell's graph. A parent-only closure binding was tested and rejected because it did not refresh that graph. Navigation hit targets are separated from disclosure: header/address/entry navigation remains, but shrinking a disclosure cannot also activate an enclosing card gesture. The production flow layout, required-width fitting, automatic self-sizing, loader/cache, three measured visual rows, hidden count and ranking are preserved. No offset compensation, scrollTo, scrolling suppression or production delay.
- **Filter:** restored `c551de97`'s original SwiftUI Button/popover and native shared Map/Filter `ToolbarItemGroup`. The constant `.navigationBarTrailing` group removes the conditional ToolbarContent conformance warning without changing deployment/language/project settings. A native mounted test reproduced the remaining race: a dismissal acknowledgement overwrote a newer reopen request. `CompetitionFilterPresentation` separates requested visibility from active presentation, scopes acknowledgements by generation, and queues reopening until UIKit transition completion. The tiny completion probe retains its callback when a Region sheet merely covers the popover. No timeout, cooldown, disabled taps, Menu, split capsule or custom glass. The attempted custom UIKit Filter adapter was rejected and removed.
- **All Results:** the old dimmer belonged to an individual page ScrollView, with an opacity-plus-scale transition on the whole overlay; it could not block sibling navigation/tab controls. One native over-full-screen presentation now fades the existing card/dimmer across the whole scene and intercepts background interaction, including accessibility. Its presenter remains mounted. X/backdrop clears selection only after dismissal; direct X-only and round-origin Back semantics remain. The existing Profile view is pushed/popped in the modal's native navigation controller. Providers, selections, loading and advancement calculations are unchanged.
- **Padding:** minimum/intrinsic width left short event tables narrower than the padded card. The shared card now supplies its known viewport width (card width minus the existing two 22pt insets) to every event table, including the painted inner stack. Long tables retain their minimum width and horizontal scrolling. Surplus width goes between Round and statistics; fixed columns, scores, record reserves, row heights and badge geometry are unchanged. No per-event offsets. The final 402pt simulator check measures each short table at 326pt and the screenshot confirms equal painted-edge insets.
