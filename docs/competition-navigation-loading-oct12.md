## Implemented

- Top Cubers is mounted in **Competitions list cards**, not competition detail pages. The old parent-state loader published into a dictionary, but the virtualized coordinator's presentation signature did not include those updates. Its hosted row therefore retained a snapshot until an unrelated reconfiguration. `CompetitionLoadedTopCubers` now owns an observed loader inside the actual hosting cell: warm data renders immediately, persisted cache is checked first, and a cold fetch starts without another section's loading gate. Existing cache and in-flight deduplication remain. DEBUG WCIF response/parse and loader timings distinguish network latency from presentation latency; the physical five-second interval has not been measured here.
- The disclosure jump was reproduced with actual swipes and ample content below the card: the estimated compositional group subtracted the entire 595pt row-height reduction from the viewport offset (556pt to -39pt), although 556pt remained legal. The single-column list now uses `CompetitionVerticalListLayout`, a native flow layout with required-width/content-derived-height hosting-cell fitting and automatic constraint-driven self-sizing. This removes the estimated group's anchoring behavior at the layout source, not through compensation. Diffable identity, cells, refresh, paging, native scroll registration and the iOS 15 hosting fallback remain. Three measured visual rows, hidden-person counts, ordering, transitions and Reduce Motion handling are unchanged. No disclosure `setContentOffset`, `scrollTo`, anchor compensation or focus adjustment was introduced; the existing filter/query-change reset is untouched.
- Official By Competitor, WCA Live My Results, CubingChina Live My Results, and CubingChina Sum of Ranks use the shared competition-level All Results card. Known published content is immediate; Live reuses existing competitor endpoints, validated registration/round identity, exact My Results WCA-ID matching, owned cancellation and retry. Direct entries have X but no Back; round-origin entries retain Back. The empty event/round presentation context is never sent as a provider request.
- One competition-wide All Results column plan measures every round name and score, reserves record space, and is reused by all event sections. Missing average/best slots are blank; best-only rows no longer shift columns. Long scores remain horizontally scrollable. Semantic emphasis and existing result formatters remain; long titles reserve space for X. The shared formatter receives explicit single/average semantics, including FMC means below 10, DNF and already-penalty-inclusive totals.
- Sum of Ranks uses legible subheadline text, 4pt rather than 9pt row padding, 34pt headers, 46pt event columns, and width-adaptive leading columns. Position, Competitor and complete Region fit normal compact content widths (288/343/398pt). Region can wrap, while long competitor names truncate. Sum is also visible when practical; the event columns remain horizontally scrollable. Gender, server order, ties and data are unchanged. Rows invoke the shared competitor-card route.
- The selected Live header and results list have exactly one outer `CompetitionResultsSurface`. Its existing 4pt radius, black shadow (opacity 0.12, radius 1.5, y 1), and dark ambient lift (white opacity 0.065, radius 4, y 2) match the selector/list treatment. Inner list decoration is disabled.
- The gap between capsules and destination navigation is 8pt instead of 12pt. Capsule sizes/colors/44pt targets and measured event-heading ink alignment are unchanged.
- Filter now uses a standard native `Menu`: Event and Status submenus, Past-only Year, the existing searchable Region/Country sheet, Top Cubers toggle and localized information action. Existing AppStorage bindings and event multi-selection semantics are retained. On iOS 26+, a native fixed `ToolbarSpacer` separates Map and Filter backgrounds; older systems retain their toolbar grouping. The menu is no longer a custom Filter popover or anchored to a shared two-action capsule.
