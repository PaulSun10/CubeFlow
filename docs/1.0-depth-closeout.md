# 1.0 Depth Pass Closeout

2026-10-05. Continued across interruptions from the same intentionally dirty worktree. No commit, push, deployment, destructive migration or broad test suite. Prior Smart Cube/Combined/Explore/Competition changes were preserved, not attributed to this pass.

## Implemented

- Data rows restore an independent measured monospaced number column and 28-point Dynamic Type primary time, retaining event/input/date/scramble provenance and a stable trailing affordance.
- Selection uses native SF circle/checkmark presentation. The physically ineffective UIKit hold/drag bridge was omitted because its view-discovery/gesture arbitration was fragile. Ordinary scrolling, direct selection and Select to Here remain.
- Select to Here uses the actual near edge of the floating control and includes a partially visible adjacent row; symmetric top/bottom behavior follows filtered display order. Native Glass uses the established availability wrapper; older systems retain their fallback.
- Move uses native session rows/counts, a close icon and destination confirmation before mutation. The existing relationship-only move path preserves solve-owned data.
- PB values reuse the original My Results adaptive semantic palette, verified against source/history; blue/orange celebration is separate. Full-screen confetti is noninteractive, bounded to 3.2 seconds and cancels/replaces by result identity; Reduce Motion keeps the static PB indication. Current-result PB persists beyond animation until the next result, timed solve or relevant context change.
- FTO now has a pinned MIT random-state engine, serial off-main Timer generation, context-safe prefetch, notation/state model, 72-sticker diagram, palette, existing Data/statistics/event workflow and backup/export support.
- NxN outer clipping is repaired at backing-canvas/stroke/compositing level, not hidden with SwiftUI padding.
- Square-1 diagrams are rendered from legal setup states into a fully padded top/bottom canvas. The image cache is bounded. Four known legacy baseline exceptions retain old images without guessed correction.
- Added 967 Square-1 PBL recognition/setup references and 16 FTO edge-cycle references, with explicit source/license/reference labelling. Set Info uses plain native `info`; no Alg navigation/trainer redesign.
- Native backups preserve optional input provenance and opaque reconstruction bytes, including future source values. Legacy omission does not erase existing metadata. csTimer export partitions mixed-event sessions only in the export, emits current FTO/OH/BLD IDs, and maps the fast 4x4 practice variant to 4x4 rather than 3x3.
- Six new content/confirmation keys validated across all 19 touched localization catalogs. Existing unrelated catalog changes remain intact.

It adds about 1.1 MiB of PBL JSON, 1.4 MiB of FTO images and a 40 KiB MIT engine. `git diff --stat` includes substantial pre-existing work and excludes new untracked resources; it must not be presented as this pass's entire ownership.
